# Employee Performance Dashboard

## 📊 Project Overview

The **Employee Performance Dashboard** is an interactive dashboard designed to analyze and monitor employee performance using key performance indicators (KPIs). It provides a clear overview of employee productivity, achievements, work quality, and task completion.

The dashboard helps organizations understand employee performance and identify areas that may require attention or improvement.

---

## 🎯 Objectives

* Monitor overall employee performance.
* Analyze employee productivity.
* Track achievement against assigned targets.
* Measure work quality.
* Monitor completed tasks.
* Provide an easy-to-understand visual summary of performance data.

---

## 📌 Key Performance Indicators (KPIs)

### 1. Employee Count

**Employee Count** represents the total number of employees included in the performance analysis.

**Example:**

```text
Employee Count = 100
```

If the dataset contains 100 employees, the dashboard displays **100 employees**.

---

### 2. Productivity %

**Productivity** measures how efficiently employees complete their assigned work.

**Formula:**

```text
Productivity % = Completed Tasks / Assigned Tasks × 100
```

**Example:**

If an employee is assigned 50 tasks and completes 45:

```text
45 / 50 × 100 = 90%
```

Therefore, the productivity is **90%**.

---

### 3. Achievement %

**Achievement %** measures the percentage of assigned goals or targets that employees have successfully achieved.

**Formula:**

```text
Achievement % = Actual Achievement / Target × 100
```

**Example:**

If the target is 100 and the employee achieves 85:

```text
85 / 100 × 100 = 85%
```

Therefore, the achievement percentage is **85%**.

---

### 4. Quality Score %

**Quality Score** measures the quality, accuracy, and effectiveness of an employee's completed work.

**Example:**

If an employee receives quality scores of 90%, 85%, 95%, and 90%:

```text
Average Quality Score = (90 + 85 + 95 + 90) / 4
                       = 90%
```

Therefore, the average quality score is **90%**.

A higher quality score indicates better work quality and accuracy.

---

### 5. Task Completion

**Task Completion** represents the number of assigned tasks that employees have successfully completed.

**Formula:**

```text
Task Completion % = Completed Tasks / Assigned Tasks × 100
```

**Example:**

If 500 tasks are assigned and 450 are completed:

```text
450 / 500 × 100 = 90%
```

Therefore, the task completion rate is **90%**.
